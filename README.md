# Neon Rush — Rhythm Platformer

Neon Rush is an original browser rhythm-platformer with auto-running gameplay, cube jumping, spike patterns, raised blocks, pits, increasing level speed, and five handcrafted courses. It uses original canvas-drawn visuals and synthesized sound effects. It does **not** include Geometry Dash's proprietary code, levels, art, or music.

## Play locally
Open `index.html` in a modern desktop browser.

- **Jump:** Space, Up Arrow, W, mouse click, or tap the game screen
- **Pause / resume:** Escape or P
- **Restart:** R or the Restart button
- **Levels:** use LEVELS in the header; completing a level unlocks the next
- **Practice mode:** restarts from automatic quarter-level checkpoints after a collision
- **Sound:** use SOUND ON/OFF in the header

Progress and unlocked levels are saved in local browser storage when available. The game is a static HTML file and requires no build tools or server.

## Publish with GitHub Pages
1. Open this repository.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**, then press **Save**.
5. Wait for deployment to finish. GitHub displays the published URL in the Pages settings. It should be similar to `https://talonterry15-cmd.github.io/Geometry-dash-/`.

The URL is not confirmed live until GitHub Pages reports a successful deployment. If the page does not load, check the Pages status and confirm the repository's Pages source is set to `main` / root.
