# Neon Rush — Rhythm Runner

An original single-file browser platformer inspired by auto-running rhythm games. It uses original canvas-drawn visuals and five handcrafted obstacle courses; it does not include Geometry Dash's proprietary levels, art, music, or code.

## Play locally
Open `index.html` in a modern desktop browser. Controls: **Space**, **Up Arrow**, **W**, click/tap to jump; **Esc** pauses; **R** restarts. Sound can be toggled in the header. Progress and unlocked levels are saved locally in your browser.

## Publish with GitHub Pages
1. Open this repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**, then press **Save**.
5. Wait for the Pages deployment to finish. GitHub will show the public site URL in the Pages section. It will usually look like `https://talonterry15-cmd.github.io/Geometry-dash-/`.

If the Pages option does not appear, refresh Settings or confirm the repository is public. The public URL is not live until GitHub Pages has completed deployment.
