# Neon Rush — Rhythm Platformer

Neon Rush is an original, no-ad browser rhythm-platformer. It includes auto-running cube gameplay, five handcrafted courses with different speeds and obstacle patterns, spikes, raised blocks, jump pads, a finish line, pause/restart controls, level selection, practice mode, progress percentages, saved best runs, and synthesized sound effects.

This is an original game inspired by the broad genre of one-button rhythm platformers. It does **not** include Geometry Dash's proprietary code, levels, art, or music.

## Play locally

Open `index.html` in a modern desktop browser.

- **Jump:** Space, Up Arrow, W, mouse click, or tap/click the game area
- **Pause / resume:** Pause button or Escape
- **Restart:** Restart button
- **Levels:** LEVELS in the header
- **Practice mode:** select Practice Mode on the start screen
- **Sound:** SOUND ON/OFF in the header

Best-run percentages are stored in local browser storage when available. The game is a static HTML file and requires no build tools, libraries, or server.

## Publish with GitHub Pages

1. Open this repository.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**, then press **Save**.
5. Wait for deployment to finish. GitHub displays the published URL in the Pages settings. It should be similar to `https://talonterry15-cmd.github.io/Geometry-dash-/`.

The public URL is not confirmed live until GitHub Pages reports a successful deployment. If the page does not load, check Pages status and confirm the source is set to `main` / root.
